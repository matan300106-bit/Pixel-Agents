# Cat Town — city plan (owner answers, 2026-10-06)

## Rules (shown in every video)
- Every new follower = 1 new cat + a home + (in the video) a name tag "@name · Cat #N moved in" for a few of them.
- Most-liked comment builds anything, **cat version** ("a cat airport", "a cat pizza place"). Rude, political or unsafe asks are skipped → next most-liked.

## The city
| Topic | Decision |
|---|---|
| Name | **Cat Town** (petme2.com/cat-town) |
| Day 1 | Empty land. Only the roundabout with Mango's PETME2 water fountain, and Mango. |
| Land | Coast + mountains: green land, a beach and sea on one side (room for a harbor later), mountains behind (hills for big landmarks). |
| Style | **Modern cat city**: clean streets, road grid, cars, tall cat apartment towers as it grows. Cat ears on every roof, round cat-flap doors. |
| Homes | Followers 1–100: small cat houses. From 101: cat apartment towers, one apartment each; a tower grows one floor at a time (lit window = new cat). |
| Mango | Orange tabby, the first resident, lives next to the fountain. |
| Brand | Small and natural: Mango's PETME2 fountain in the center + a small PETME2 pet shop. No sales talk in videos. |
| Milestones | **100 followers: City Hall + Mango becomes mayor.** (More milestones can be added later.) |
| Schedule | One episode **every day**. Needs: new follower count + top comments with likes (from Instagram). |

## Daily episode (about 20 s)
1. "Day N" title over the roundabout.
2. Fly down a street while new homes pop up + name tags, counter climbs.
3. Rise to show the whole city.
4. Comment card scrolls to the most-liked comment (gold, 👑, likes count up).
5. The build appears (confetti, "built by @name" tag).
6. End: "What do we build tomorrow?" + the two rules + @petme2.

Engine: `town2.html` (Three.js, rendered to 1080×1920 30 fps) + voice (edge-tts, Ava) + original music + sound effects.
