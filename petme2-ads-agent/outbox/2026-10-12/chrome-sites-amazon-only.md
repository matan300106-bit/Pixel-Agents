# PETME2 Amazon Ads: show ads ONLY on Amazon (all campaigns)

You are helping PETME2 on Amazon Ads (advertising.amazon.com, US). Sponsored Products.
Owner: "Sites: ONLY Amazon, for all products." Ads must show only on Amazon (website + app). No third-party / off-Amazon sites.

## Rules
- Change ONLY the "Sites" / site placement setting. Nothing else: no bids, budgets, strategy, placements %, states.
- Never pause anything. Never click "Apply" on recommendations.
- If logged out, 2-step code or CAPTCHA: stop and tell me.

## Steps
1. Campaign Manager → Sponsored Products. Filter: **All but archived** (enabled AND paused, because paused ones may be turned on later).
2. For **every** campaign: open it → **Settings** (or **Placements**). Find the setting for where ads show, often called **"Sites"**, **"Ad placements on sites"**, or **"Amazon and third-party sites"**.
3. Set it to **Amazon only**. Turn OFF every third-party / off-Amazon site option. Save.
   - If there is a separate **Amazon Business** option, leave it as it is and write it down.
   - If the campaign has no such setting, write "no Sites setting" (then it is Amazon only already).
4. Also check: Campaign Manager → **Settings / account settings** for any account-level default like "Show Sponsored Products ads on third-party sites". If found, set it to Amazon only / off.
