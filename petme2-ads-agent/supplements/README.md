# PETME2 new supplements: packaging DRAFTS

These are **drafts**, not final print files. They are copies of your existing
packaging files with new text. The layout, colors, leaves, animal drawings, icons and
dieline are the same as the originals.

| File | What it is |

- The PDFs are vector files and use the **same page size** as the originals
  (box: 1366 x 1003.73 pt; label: 850.39 x 155.91 pt), so they still fit the printer's template.

   - Cat Grass, per 2 soft chews (4 g): Wheatgrass (Cat Grass) Powder 150 mg, Pumpkin Powder
     120 mg, Psyllium Husk 100 mg, Inulin (Chicory Root) 50 mg, Papaya Powder 20 mg,
     Bacillus coagulans 100 Million CFU.
   - Tear Stain, per 2 soft chews (4 g): Cranberry Extract 100 mg, Eyebright 60 mg,
     Marshmallow Root 50 mg, Colostrum 50 mg, Vitamin C 20 mg, Lutein 2 mg,
     Bacillus coagulans 100 Million CFU.
2. **Guaranteed Analysis = "TBD".** All the % numbers are now "TBD". The manufacturer must
   give the real numbers for the new formulas.
3. **Inactive ingredients, warnings, cautions, directions and the address** are copied from
   the old products. Please check that they are still true for the new formulas.
4. The short text on the jar labels is new:
   - Cat: "Cat Grass Digestive Supplement / Supports healthy digestion and / helps manage hairballs"
   - Dog: "Tear Stain Supplement for Dogs / Supports a clean, bright eye area"

## The "VETERINARIAN FORMULATED" badge was removed

The round badge was removed from the front panels and the jar labels. We cannot prove this
claim for the new formulas. Add it back only if a veterinarian really made the formula
and you can show proof.

## Side panel icons: a designer should change them

The icon labels are new ("Supports Digestion", "Hairball Support", "Daily Gut Care" for
cats; "Clean Eye Area", "Reduces Look of Stains", "Daily Support" for dogs), but the
**icons are the old ones** (coat/skin icons for cats, joint icons for dogs). A designer
should replace them with icons that match the new text.

## Problem we found in your EXISTING design

The Skin & Coat **jar label** says **"200 CHEWS"** and **"per 2 soft chews (2g)"**.
The Skin & Coat **box** says **"100 CHEWS"** and **"(4g)"**.
Both say NET WT. 7.05 OZ (200 g). They cannot both be right.
In the new Cat Grass label we used **100 CHEWS** and **(4g)**, the same as the box.
**Please confirm the real chew count and chew weight** with the manufacturer.

## Other notes for the designer

- Fonts: titles use Source Serif 4 Bold, and body text uses Liberation Sans. Liberation Sans
  has the same letter widths as Arial. The fonts are embedded in the PDFs. The designer can
  change the text to the real Source Serif / Arial fonts in Illustrator.
- The old text and the old outlined art (badge, old subtitle, old values) were **deleted**
  from the file. They are not just covered, so nothing old is hidden under the new text.
- The dog title uses 3 lines ("TEAR STAIN / EYE AREA / SUPPORT"), so it fills the same
  space as the old 3-line titles. "Eye Area" also appears in the gold line below. If you
  do not want the words twice, you can change one of them.
- The dog pill text was "FOR DOG". We changed it to "FOR DOGS".
- Colors are CMYK, the same as the original files.
